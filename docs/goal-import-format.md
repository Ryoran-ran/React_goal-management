# 技術目標の一括入力フォーマット

アプリの入力項目に合わせた5列の表です。1行につき1目標を記入します。

| 技術目標                   | カテゴリ | 優先度 | 達成条件 | メモ                                           |
| -------------------------- | -------- | ------ | -------- | ---------------------------------------------- |
| 体重移動を最後まで完了する |          | 高     |          | 次の動作を急ぎ、乗り切る前に次へ行く箇所がある |

- 技術目標：必須、200文字以内。
- カテゴリ：下記のいずれか1つ。未確定なら空欄にして、登録前に選択できます。
- 優先度：低・中・高のいずれか。
- 達成条件：できたと判断するための条件。未定なら空欄。
- メモ：指摘や補足。未定なら空欄。

空欄の列も省略せず、必ず5列にします。Markdown表またはタブ区切りに対応します。タブ区切りではセル内の改行・タブを使わず、1行にまとめてください。Markdown表のセル内に `|` を含める場合は `\|` と記入します。

カテゴリ名：全体、ラテン、モダン、チャチャチャ、サンバ、ルンバ、パソドブレ、ジャイブ、ワルツ、タンゴ、ヴェニーズワルツ、スローフォックストロット、クイックステップ。

状態・進捗は新規登録時に「未着手・0％」になります。目標日、親目標、関連イベント、画像は登録後の編集画面で設定できます。

## 元データの変換を依頼する文

以下の指示と、整理したい元データを一緒に渡してください。

```text
以下の目標一覧を、アプリへの一括入力用のMarkdown表に変換してください。
列は必ず「技術目標｜カテゴリ｜優先度｜達成条件｜メモ」の順で5列にしてください。
1行につき1目標とし、目標を省略・統合しないでください。
優先度は「低・中・高」を使用し、★★★は高、★★☆は中、★☆☆は低に変換してください。
元の具体的な指摘は「メモ」に入れてください。
達成条件は明示されている場合だけ記載し、数値・回数などを勝手に作らないでください。
カテゴリは、こちらが指定した分類に従ってください。未確定のカテゴリと達成条件は空欄にし、列自体は残してください。
カテゴリに使える値：全体、ラテン、モダン、チャチャチャ、サンバ、ルンバ、パソドブレ、ジャイブ、ワルツ、タンゴ、ヴェニーズワルツ、スローフォックストロット、クイックステップ。
出力は表だけにしてください。
```
