# Dance Note — 社交ダンス目標・練習管理

自分で決めたテーマに、教わったことと練習の気づきを積み重ねる個人用Webアプリです。React・TypeScript・Viteを使用し、テーマ・記録・画像・動画はDexie経由で端末のIndexedDBに保存します。バックエンドやアカウントはありません。YouTubeは外部リンクとして開きます。

## 起動

公開版: https://ryoran-ran.github.io/React_goal-management/

GitHub Pagesはアプリの配信に使います。記録・画像・動画は閲覧しているブラウザのIndexedDBに保存され、GitHubへのアップロードや端末間の自動同期はしません。ローカル版と公開版は保存先が異なるため、既存の記録はローカル版の「整理」→「エクスポート・インポート」で書き出し、公開版で読み込んでください。

Node.js 22.12以降を使用してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開きます。通常は `http://127.0.0.1:5173/` です。

```sh
npm test
npm run build
npm run preview
```

`npm run preview` は通常 `http://127.0.0.1:4173/` で本番用ファイルを配信します。開発サーバーではService Workerを登録せず、本番ビルドでPWAを有効にします。

## 使い方

日付欄はアプリ共通のカレンダーで選択します。レッスンがある日は緑の背景と目印、土曜は青・日曜は赤で表示します。中止した回は除き、振替は変更後の日付に表示します。「整理」→「カレンダー設定」の「週の開始曜日」で日〜土から選べ、変更は自動保存されます。同じブラウザで保持し、次に開くすべての日付選択カレンダーに反映します（週次計画の月曜始まりは変更しません）。年月の見出しから月・年を切り替えられます。任意の終了日は「未設定にする」で空欄に戻せます。カレンダーを閉じるだけでは日付を変更しません。

予定一覧の「月ごと／日ごと」は同じブラウザで保持します。画面移動・再読み込み・アプリの開き直し後も、最後に選んだ表示単位を使います。この表示設定はブラウザごとの設定で、バックアップや端末間の同期対象には含めません。

1. **今日の予定から記録**：「今日」の上部に当日のレッスン・自主練習が並びます。レッスン後に「記録する」を押し、元の予定にカテゴリ別の内容・指摘・宿題を残します。記録済みの予定は「記録を見る・編集」から開けます。別の日の記録や予定の追加は「ほかの日の予定・予定の管理」から進めます。中止した予定はここには表示しません。
2. **学びの記録**：予定で保存した記録をカテゴリ別に見返します。予定と別に残したいメモは左下の＋から追加でき、テーマ未分類や動画だけの記録も可能です。日付はメモを書いた日ではなく、レッスン・練習をした日を選びます。同日に複数の記録を残せます。「今日」の予定の下には取り組むテーマが並び、種目・目指す状態・次に試すことを必要な分だけ設定できます。
3. **練習前に見返す**：テーマには直近の「次に試すこと」と、日付順の記録が表示されます。練習後は「練習を振り返る」から、できたこと・難しかったことをひと言残します。次に試すことが空欄の記録でも、以前の方針は残ります。
4. **予定**：自主練習・単発レッスン・毎週のレッスンを登録します。見出し横の「月／日」で表示単位を切り替えます。日付欄と左右の矢印で表示期間を選び、カレンダー内の「今日を選ぶ／今月を選ぶ」で現在に戻れます。その日のレッスンと自主練習をまとめて表示します。「絞り込み」を開くと予定・記録済み・中止を選べ、閉じていても選択中の条件をボタンに表示します。日ごとの表示から単発の予定を追加すると、表示中の日付が初期入力されます。保存後は保存した日付の一覧に戻ります。当日や過去の予定の「記録する」から「今日」と同じ記録画面を開けます。予定の既存メモや資料は保持します。各回の日付変更・中止もここから行えます。繰り返しの基本設定は「整理」→「繰り返しレッスン」から管理します。
5. **大会など**：競技会・メダルテスト等の日付を管理します。テーマの編集画面で大会を関連付けると、目指す状態と残り日数を一緒に確認できます。イベント一覧では完了・中止を初期状態で非表示にし、「完了・中止も表示」で切り替えられます。表示設定は同じブラウザで保持し、非表示にしてもイベントや添付資料は残ります。
6. **整理**：AI相談用プロンプト、エクスポート・インポート、繰り返しレッスンの管理、カレンダー設定、週月の計画・以前の記録にアクセスします。毎日の記録では設定不要です。

「整理」→「レッスンをAIに相談」では、開始日・終了日と相談したいことを入力し、対象の記録を含むプロンプトをコピーできます。初期期間は今日を含む直近30日です。期間は保存日時ではなくレッスン日・メモの日付で判定し、両端の日付を含みます。期間を変更すると全件が選択され、チェックで不要なレッスンを外せます。「全選択・全解除」も利用できます。同じレッスンのカテゴリ別の内容・指摘・宿題と全体メモは一つの選択項目にまとめ、個別に残した学びのメモは別項目にします。日付・名前・カテゴリを一覧で確認でき、内容は各項目の「内容を確認」で開きます。選んだ記録だけをプロンプトに含め、0件ではコピーできません。中止した予定、内容のない予定、自主練習は除外します。画像・動画は件数のみ、YouTubeはリンクを含め、ファイル本体は含めません。大会の振り返りは任意の入力欄に大会名・日付・本番での気づきを書くと、選んだレッスンと一緒に渡せます。この振り返り入力は大会データには保存しません。アプリからAIには送信せず、コピーした文章をChatGPTなどに貼り付けて使います。コピーできない環境ではプレビューから手動でコピーできます。

テーマは自動作成しません。新しいテーマは左下の丸い＋から追加できます。「今取り組む」「いったんお休み」「できるようになった」で整理でき、休止・完了後も記録は残ります。記録は後からテーマを付け直せます。

「学びの記録」には「予定」で保存したレッスン内容もカテゴリごとに表示します。日付・レッスン名と、取り組んだ内容・指摘・宿題を一覧で見返せます。カテゴリ・キーワード・テーマで絞り込み、カードから元のカテゴリの編集画面を開けます。独自カテゴリ、画像・動画だけ、YouTubeだけの記録にも対応します。レッスン全体のメモや実施済みの自主練習メモも表示します。内容のない予定・中止した予定は表示しません。件数はカテゴリ別の記録をそれぞれ1件として数えます。元データを直接参照するため、転記は不要で、編集・削除も一覧に反映されます。テーマとの既存の関連も引き継ぎます。

Enterだけでは保存せず、Ctrl＋Enterまたは保存ボタンで保存します。画像（JPEG・PNG・WebP・GIF）と動画（MP4・WebM・MOV）は原本を保存し、保存後にファイル名から表示できます。動画の再生可否はブラウザの対応形式に依存します。YouTubeはリンクから開きます。

DBはバージョン3です。既存の9ストアを変更せず、`themes` と `learningNotes` を追加します。以前の目標47件などを自動でテーマに変換せず、記録・資料・繰り返し設定を保持します。新しい記録と予定の実施状態、資料の保存はひとつのトランザクションで確定します。

以下は「整理」と「予定」から使える既存機能の詳細です。

## バックアップと引き継ぎ

「整理」→「エクスポート・インポート」から利用します。

- **エクスポート**：「すべてのデータをエクスポート」で、日付入りの `.dancenote` ファイルをダウンロードします。予定・レッスン・自主練習・学びのメモ・テーマ・イベント・週月の計画・設定に加え、画像・動画の原本とサムネイル、YouTubeのリンクを含みます。YouTubeの動画自体はダウンロードしません。
- **インポート**：このアプリでエクスポートしたファイルを選び、作成日時・現在の件数・読み込む件数を確認します。置き換えのチェックを入れて「この内容で復元する」を押すと、現在の全データをバックアップの内容に置き換えます。追加・マージは行いません。現在の記録を残す場合は先にエクスポートしてください。ファイルを選ぶだけではデータは変更されません。
- **別の端末へ引き継ぐ**：バックアップファイルを別の端末へ移し、同じアプリのインポート画面から復元します。ID・日時・関連付け・独自カテゴリ・繰り返しの設定も保持します。復元した時点より先の繰り返し予定は、予定画面を開くと通常どおり補充されます。

ファイルの読み書きは端末内で完結します。バックアップは暗号化されていないため、個人の記録として保管してください。復元は全テーブルを1つのトランザクションで処理し、容量不足などで失敗した場合は置き換え前の状態を保持します。

バックアップ形式はバージョン1（DBバージョン3）です。固定ヘッダー、JSONの記録データ、画像・動画のバイナリを1つのファイルに格納します。SHA-256で記録データと各メディアの破損を検出し、形式・項目・重複・メディア関連付けを復元前に検証します。JSON部分の上限は32 MiBで、画像・動画はこの上限に含まれません。メディアの検証は1ファイルずつ行います。

## 技術目標の廃止

技術目標の一覧・精査・追加・選択画面を削除しました。次回起動時に既存の技術目標とその目標専用の添付資料を削除し、イベント・計画・記録から参照を取り除きます。テーマやレッスン・自主練習、宿題、記録の添付資料は保持します。計画の「細かく見るポイント」は週の振り返り・月のメモへ移し、技術目標を通じて明示的に関連付けた記録とテーマは直接の関連として保持します。テーマの自動作成は行いません。

旧バックアップの読み込みでも同じ整理を実行し、技術目標を復活させません。復元前の確認に除外対象を表示します。データ形式には旧バックアップとの互換性のため空の目標ストアと旧参照フィールドを残しています。データ整理は全体を1つのトランザクションで行い、失敗した場合は元の状態に戻ります。

## イベントのマイルストーン・ガント

マイルストーン（到達点・確認方法・期限）と作業（実施内容・予定期間・状態・優先度）を別の項目として管理します。作業は各マイルストーンの「このマイルストーンに作業を追加」から登録し、追加元に自動で紐づきます。作業フォームにはマイルストーンの選択欄を設けず、見出しの下に所属先を表示します。作業の編集・削除は作業名から行い、複数登録時は「保存後に次の作業を追加する」で同じマイルストーンへの登録を続けられます。未分類の作業を新しく追加する操作はありませんが、以前の未分類データは引き続き閲覧・編集できます。作業がすべて完了しても、マイルストーンの達成は手動で判断します。

「大会など」でイベントを選ぶと「準備スケジュール」を開きます。一覧は「イベント → マイルストーン → 関連する作業」のツリー表示です。マイルストーンの期限は日付の指定、またはイベントの何日前かで入力できます。作業の開始予定日・期限は任意です。各編集画面で保存または Ctrl＋Enter で確定します。以前にマイルストーンへ登録した開始日は履歴用に残し、編集画面の「以前に登録した開始日」から解除できます。

一覧とガントは同じデータを表示します。ガントは週・月・全期間を切り替えられ、マイルストーンは◆で表示します。当初計画（灰色）・現在の計画（緑）・実績（青）を比較できます。赤線は今日、紫線は開催日です。実績は実際の開始から完了までの経過期間で、練習時間の合計ではありません。取り組み中で開始実績がある場合は今日までを表示します。

スマホでは日付を縦、マイルストーンを横に並べます。「全期間」で準備開始から開催日・最後の予定までを見渡せます。見出しをタップすると隣に関連作業の列が開き、ほかのマイルストーンと比較できます。薄い帯は完了分も含めた関連作業の最初から最後までの範囲で、途中の空白期間も含みます。未分類の作業も独立した列にまとめます。日付と見出しを固定し、上下に日付、左右に項目をスクロールできます。マイルストーンは「到達点を編集」、作業は見出しから編集します。PCでは従来の横型を初期表示し、「表示方向」でどちらの端末でも縦・横を切り替えられます。横型では項目名から編集できます。

当初計画は最初に予定日を設定した時点で保存し、その後に日程を変更しても上書きしません。変更前後の日付・変更日時・任意の理由を履歴に残します。「期限超過」と「当初より何日後ろにずれたか」を区別して表示します。開始日を未設定にした項目は期間を推測せず、期限の点のみで表示します。達成は手動で設定し、実際の達成日を残します。レッスンの記録や期限の経過で自動的に達成扱いにはしません。

開催日を変更した際は、未達成の節目・未完了の作業の予定を同じ日数ずらすか選べます。チェックしなければ日付は維持します。ずらす場合も当初計画・実績・達成済み・見送り・完了作業は維持します。「何日前」で入力した日付も通常の日付として保存し、後日の開催日変更はこの操作で判断します。

達成・見送りの節目は通常非表示で、表示チェックから確認できます。「今日」の次の舞台にはイベントごとに次の未達成の節目を表示し、予定一覧には該当日の未達成の期限を表示します。完了・中止したイベントの期限は予定一覧から除きます。イベントが完了しても未達成の節目を自動完了にはせず、記録として保持します。

マイルストーンと作業はイベント内の別々の配列として端末に保存し、当初計画・実績・変更履歴もエクスポート・インポートに含めます。従来のチェックリストは起動・インポート時に独立した作業へ一度だけ移行します。名前・完了状態・関連先を保持し、記録のなかった予定日・完了日は空欄のままにします。マイルストーンを削除しても関連する作業は「未分類」に残ります。イベント自体を削除した場合は、そのイベントのマイルストーン・作業・履歴も削除されます。

参考: [ChatTask のガント](https://github.com/Ryoran-ran/tauri-ChatTask/blob/main/chattask-desktop/src/components/GanttModal.tsx)、[マイルストーン管理](https://github.com/Ryoran-ran/tauri-ChatTask/blob/main/chattask-desktop/src/components/GoalsModal.tsx)。期間表示・当初計画と実績の比較を参考に、このアプリではタッチでのスクロールと別画面での編集にしています。

## 毎週のレッスン予定

レッスン内容は、一覧の左下にある「＋ レッスン内容を追加」を押して記録欄を追加してから、開いた画面でカテゴリを選びます。カテゴリは初めから指定されず、「新しいカテゴリを追加」で自由な名前を入力することもできます。一覧にはカテゴリ名、内容・指摘・宿題の記入状況、資料の件数を表示し、カテゴリ名から再編集できます。画像・動画・YouTubeも同じ画面で編集でき、「← 戻る」で未保存の入力やファイル選択を保持して一覧に戻ります。未選択の記録は「カテゴリ未選択」と表示し、カテゴリを決めてからレッスン画面の「保存して一覧に戻る」で確定します。

週・月の計画では、取り組むこと・月の到達点・振り返りを記録できます。保存ボタンまたはCtrl＋Enterで保存します。

追加後の入力画面で「カテゴリ」→「＋ 新しいカテゴリを追加」を選ぶと、「ストレッチ」「サルサ」など自由な名前を入力できます。レッスンを保存すると、次回以降も「追加したカテゴリ」から選べます。同名のカテゴリは重複登録しません。

各回の「記録する」→「カテゴリ別のレッスン内容」で「＋ レッスン内容を追加」を押し、パソドブレ・ルンバなどのカテゴリと「取り組んだ内容」「先生からの指摘・アドバイス」「次回までの宿題」を入力します。全体・ラテン・モダンも選べます。宿題は次のレッスンの「前回の宿題」にカテゴリ名付きで表示します。以前の記録は「レッスン全体のメモ・資料」に保持します。

カテゴリごとに画像、動画ファイル（MP4・WebM・MOV）、複数のYouTubeリンクを登録できます。画像・動画は端末のIndexedDBに原本を保存し、保存後に資料名を押すと表示・再生します。ブラウザが動画の形式に対応していない場合は「動画を端末に保存」でプレーヤーから開けます。YouTubeはリンクのみ保存し、「YouTubeで開く」で視聴します（通信が必要です）。カテゴリの削除はレッスンを保存した時にそのカテゴリの添付ファイルとともに反映します。

- 繰り返し設定を削除するには「整理」→「繰り返しレッスン」→対象の設定→画面下の「繰り返し設定を削除」を選びます。削除前に対象回数を確認します。自動追加が停止し、今日以降の未編集の予定を削除します。過去・記録済み・中止・振替・個別の内容や画像がある回は、単発の予定・記録として保持します。
- 大本の設定は「整理」の「繰り返しレッスン」から管理します。登録済みの設定を選ぶと、変更を反映する日・名前・曜日・時間・終了日を編集し、更新・追加・取りやめになる各回を保存前に確認できます。「指定した日から終了する」で継続を終了し、「継続する」で再開できます。過去・記録済み・中止・振替・メモや画像などを個別に設定した回は保持します。以前の終了日付き登録も一覧に表示し、設定を確認して編集できます。
- 毎週の一括登録ではレッスン名・期間・曜日・時間を設定します。各回の「記録する」で関連イベントを任意に選べます。イベントの選択はその回だけに保存され、翌週以降には引き継ぎません。
- 「予定・記録」→左下の＋→「毎週のレッスンをまとめて登録」で、開始日・曜日（複数可）を指定します。終了日は任意で、初期状態は空欄です。空欄なら終了日なしの繰り返し予定として保存します。最初の8週間を確認し、休みの日を外して登録すると、それより先もホームや一覧の表示期間に合わせて予定が追加されます。終了日を指定した場合は366日以内の期間を登録でき、指定日より先には追加しません。
- 同じ名前・日付の登録済みレッスンは再登録しません。振替・中止済みの回についても元の日付を確認して重複を防ぎます。同日に別のレッスンを入れる場合は、別の名前を付けるか「レッスンを追加」で単発登録してください。
- 1回だけ曜日が変わるときは、その回を開いて日付を変更し、変更範囲を「この回だけ」にして保存します。元の記録・画像・宿題は引き継がれます。
- 今後の曜日を変えるときは、変更を始める回の日付を変更し、「この回以降の同じ曜日の予定」を選びます。表示された日付を確認して保存すると、指定した日数だけ後続予定も移動します。対象は同じ繰り返し登録で作られた同曜日の予定だけです。別の曜日、個別に振り替えた回、中止・実施済みの回は変更せず、他の回のメモも保持します。
- 中止する回は状態を「中止」に変更します。理由を任意で記録でき、次回レッスンや予定回数からは除外されます。中止の履歴は残り、状態を「予定」に戻すこともできます。中止操作はその回だけに適用されます。
- 別曜日の追加レッスンは「レッスンを追加」から登録します。各回の内容・実施記録の編集は、その回だけに反映されます。

旧バージョンのレッスンもそのまま利用できます。繰り返し予定にはシリーズID・最初の登録日・曜日変更後の基準日を保持し、一括登録と一括変更はトランザクションで保存します。

## PWA・スマートフォン

### GitHub Pagesでの公開・更新

`main` にpushすると `.github/workflows/deploy-pages.yml` が依存関係をインストールし、テスト・Pages用ビルド・公開を実行します。リポジトリの Settings → Pages → Source は **GitHub Actions** を選びます。手動更新は Actions → Deploy to GitHub Pages → Run workflow から実行できます。

`npm run build:pages` は `/React_goal-management/` 配下用にビルドします。`npm run preview:pages` を実行し、`http://127.0.0.1:4173/React_goal-management/` で確認できます。通常の `npm run dev` と `npm run build` はルートパス用のままです。リポジトリ名を変更するときは `vite.config.ts` のPages用baseも変更します。設定は [ViteのGitHub Pages公開手順](https://vite.dev/guide/static-deploy#github-pages) に沿っています。

`dist/` は静的配信可能な本番ファイルです。スマートフォンでのホーム画面追加とService Workerには **HTTPSでの配信** が必要です（PCのlocalhostは例外）。初回にオンラインで開き、Service Workerのキャッシュが完了した後はオフラインでも起動・記録できます。更新版は開いているアプリをすべて閉じてから再度開くと反映されます。

Safariでは共有メニューから「ホーム画面に追加」、対応するChromeではインストール操作を使用します。インストール表示はブラウザ側の条件に依存します。

同じ端末でもURLのオリジン（ホスト・ポート）やブラウザが変わると保存領域は別になります。開発用URLとプレビュー用URLも別です。公開配信や実機でのオフライン動作確認は、この実装には含みません。

## 構成

主要な追加ボタンは全画面で左下に固定します。スマートフォンでは下部ナビゲーションの上に配置し、一覧末尾にボタンと重ならない余白を確保します。共通の `FloatingAddButton` を使用し、`PageHeading` の追加アクションもこの配置に統一します。編集中は新規追加の固定ボタンを表示せず、フォーム内の項目・画像追加は対象の入力欄にまとめます。

```text
src/
  types.ts                 設計書に沿った型定義
  data/db.ts               IndexedDBスキーマ
  data/repository.ts       CRUD、関連整合性、画像トランザクション
  lib/dates.ts             ローカル日付・週と月の計算
  lib/hooks.ts             Repositoryの更新購読
  lib/webmcp.ts            対応ブラウザで使える任意の操作API
  components/              入力・画像添付の共通部品
  pages/                   今日、イベント、目標、計画、練習、レッスン
public/                    ローカルPWAアイコン
```

UIからIndexedDBを直接操作しません。Repositoryが関連先の存在確認、親目標の循環検出、削除時の参照整理を担います。記録・画像メタデータ・Blobの変更は単一トランザクションで確定し、失敗時は一括で取り消します。履歴は月指定で取得し、ホームでは画像Blobを読み込みません。

DBには `events`、`goals`、`monthlyPlans`、`weeklyPlans`、`practiceLogs`、`lessons`、`attachments`、`attachmentFiles`、`settings` に、新しい `themes`、`learningNotes` を加えた11ストアがあります。将来のImport／ExportはRepository層へ追加できます。
